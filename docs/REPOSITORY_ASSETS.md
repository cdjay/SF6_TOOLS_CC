**Status**: CURRENT Governance Registry

**Audit date**: 2026-08-08

**Scope**: SF6CC `reframework` repository, its ignored local working assets, the sealed Frozen combo backup, and explicit SF6ACBCM/SF6CMFF ownership boundaries.

This registry is the long-term entry point for deciding what an asset is, who may change it, whether it belongs in a MOD release, and where its future ownership should live. It records the repository as audited; it does not migrate, delete, regenerate, or rewrite any asset.

## Classification Rules

- `SOURCE_OF_TRUTH` means authority only for the narrow role stated in **Current Authority**. It never promotes OFF data, overrides, exceptions, compatibility mappings, SQLite, or presentation records into current-game AC/BCM fact authority.
- `GENERATED` means the asset is an output. A tracked generated Runtime projection can still be required release content.
- `Writable?` describes current practical behavior, not desired policy. In particular, exception defaults are currently writable-mixed; the target three-layer ownership contract is defined in [Writable Product Data](WRITABLE_PRODUCT_DATA.md).
- `Reproducible?` is `Partial` or `Unknown` when the repository lacks all pinned inputs, build dependencies, or an audited reconstruction procedure.
- `INVESTIGATE` and `DELETE_REVIEW` are review states, not permission to delete.

Allowed Status values: `ACTIVE_RUNTIME`, `ACTIVE_RUNTIME_DATA`, `ACTIVE_TOOL`, `LEGACY_ACTIVE`, `DORMANT`, `POC`, `DEPRECATED`, `REPLACED`, `ARCHIVABLE`, `UNKNOWN`.

Allowed Data Type values: `SOURCE_OF_TRUTH`, `GENERATED`, `CACHE`, `FIXTURE`, `USER_DATA`, `RUNTIME_ARTIFACT`, `ARCHIVE`, `TEMPORARY`.

Allowed Action values: `KEEP`, `DOCUMENT`, `CONSOLIDATE`, `MOVE_LATER`, `ARCHIVE_LATER`, `DELETE_REVIEW`, `INVESTIGATE`.

## Governance Decisions Carried Forward

1. `action_runtime_compiler` and `action_compatibility` remain active for compatibility, but their future action is `MOVE_LATER`; Phase 1 performs no migration.
2. `command_display` is a generated current-build Runtime projection. Current AC/BCM data remains the authority for action relations and command routes.
