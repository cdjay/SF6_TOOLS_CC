## 范围与边界

在现有录像分析上增加总览、行为、伤害、资源四个视图，保留问题列表。
读取同一份已保存的逐帧数据，每次显示更新最多处理256行，不新增游戏钩子、原生对象缓存或录像字段。
统计窗口支持单玩家与双方对比；统计可选整场，问题仍按局筛选。查看其他局不发送任何游戏输入。
沿用既有分类与伤害账本，不增加角色 Action-ID 分支，不改变 Legacy、M5 或 Frozen V2。

纯数据计算位于 `statistics.lua`；原生绘图位于 `statistics_charts.lua`；
当前页面位于 `statistics_popups.lua`。`analysis.lua`仅编排数据批处理与带身份检查的定位。
所有图表都是原生 ImGui 绘制，不引入浏览器、网络服务或新 DLL。

## 统计定义

| 项目 | 定义 | 不能据此推断 |
| --- | --- | --- |
| 总伤害 | 原始血量减少，按原有连续受击分组求和；KO只计算实际剩余血量 | 招式理论伤害、过量伤害、漏掉的潜在伤害 |
| 造成伤害 | 只把明确记录对手为伤害来源的血量损失记给该玩家 | 来源缺失时不能默认对手造成 |
| 受伤段 | 已有伤害分组，不把连续追击每一击拆成失误 | 不必然等于完整连段或一次独立错误 |
| 状态分布 | 前后走、空中、出招、防御等互斥分类的记录帧占比 | 角色招式使用次数或可行动帧 |
| 行为雷达 | 前走、后走、空中、出招、防御、蓝防六轴，各以该字段有效帧为分母 | 不是六维能力评分；维度可重叠 |
| 方向分布 | 原始方向输入按每帧角色朝向转换为九方向 | 方向输入不等于实际位移或完整指令 |
| 方向多样性 | `-sum(p*log2(p))/log2(9)`，显示百分比 | 高熵不等于操作好，低熵不等于消极 |
| 方向变化 | 连续、同流程且两侧方向有效时计数；另给每千有效帧变化数 | 不等于APM或攻击输入次数 |
| 双方间距 | `abs(x1_raw-x2_raw)/65536`；直方图、均值、中位数、标准差、P90 | 不是碰撞箱净距或招式射程 |
| 康、防御新记录 | 连续记录中相应标记从无到有的次数 | 持续标记可能覆盖多次接触，不能当作完整命中/防御次数 |
| 资源曲线 | 当前值除以当帧上限，转成0到100%；各局分开 | 斗气归零不单独证明耗尽，下降不全是主动消耗 |
| 资源累计增减 | 只在连续、同流程、上下限有效且上限不变的相邻记录求正/负差之和 | 不跨换局把资源重置计作恢复；总变化可超过100% |

状态依据来自当前构建20004000的已采集 ACT_ST 枚举证据，不解析角色招式。
防御、受击、倒地等优先于空中，空中优先于地面出招；雷达则分别统计空中与出招，允许重叠。
缺失状态单列“状态未知”；缺失资源、标记或有效相邻差值显示未知，不能伪装成零。

## 数学与图表

- 均值和总体标准差使用在线 Welford 累积；总体标准差分母为N，不是N-1。
- 中位数与四分位采用 `1+(N-1)*q` 的相邻排序值线性插值。
- P90采用排序后第 `ceil(0.9*N)` 项，避免把它与插值四分位混为同一约定。
- 箱线图箱体为Q1到Q3，中线为中位数，须为最小到最大；不是1.5IQR离群值判定。
- 伤害直方图区间为 `<500 / 500–999 / 1000–1999 / 2000–2999 / 3000–4999 / 5000+`。
- 按受伤原因的累计伤害降序展示，悬停给出次数、单类贡献及累计贡献，用于定位主要损失来源。
- 最大三段占比为最大的 `min(3,N)` 个受伤段总和除以总受伤量；没有伤害时未知。
- 资源曲线每30帧聚合一格，保留首、末、最小、最大值；断帧或流程转换不跨段连线。
- 所有结果只描述本份录像已记录区间，不提供置信区间、总体玩家排名、长期能力评分或因果概率。

## 时钟与覆盖

仅接纳录像局数与战斗局数一致的记录。重复时钟去重，冲突或倒放则拒绝生成统计。
血量首次归零或时间两部分同时归零后，不再累积该局尾部动画；零血帧本身保留。
普通间隔缺失不补帧，求差和状态进入计数不跨缺口；缺口数量单列。

本版状态、雷达和资源均值的分母是已记录区间，包含记录到的开场等待及停顿。
它们不是“仅可操作时段”的统计。界面总览明确标注范围，录像时间按60帧/秒换算，
不等于屏幕比赛倒计时。本场第一局从192帧开始，后两局从1帧开始，不能称为完整等长采样。
`left_replay`停止原因保持原样，不能因为三局都看到KO就改为正常完整采集。

曲线点击寻找最近已有记录，不使用图形插值伪造采样。
定位下限保守采用本局连续、同流程中首次观察到倒计时下降的帧，
不是硬编码191，也不声称这是原生第一可操作帧；没有此见证就拒绝曲线定位。
本场第一局下限193，第二/三局191。原问题定位目标不受此曲线下限修改。
游戏实际不能到达时由既有定位器停止，不能跨局、写入帧号或以估算步长宣称成功。

## 交互与分级

- 点击原因条目或“回看最大受伤段”复用该项问题目标，不直接跳到伤害后的画面。
- 点击本局资源曲线使用绝对录像帧；点击其他局提示先换局，不偷偷跨局定位。
- “前往该局”单独执行原有逐局控制；整场统计时不把该按钮当作某一局。
- 接受的定位/换局操作暂时交还游戏按键，结束或失败后恢复本次主动隐藏的面板及鼠标。
- P0/P1复核层与原伤害分组独立；本地已确认漏确反可伤害为0，不制造潜在伤害。
- 原因图保持自动分类，问题表可以显示玩家确认后的描述；二者通过同一受伤段编号关联。
- 硬直差仍显示原生有符号值，未证明全局玩家归属，不通过受伤方猜正负。
