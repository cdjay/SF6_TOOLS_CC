## 3. Metamorphic and Roundtrip Evidence

The frozen corpus passed all of the following:

- repeated `load -> save -> load -> save -> load` exact object roundtrip;
- deterministic serialization;
- Frozen mechanism and metadata projection preservation;
- native/relative input-mask involution for both facing directions;
- input source priority for Runtime and conversion paths;
- `+5` frame translation of parsed press and direction events;
- normalization, grouping, scene-state, and validator idempotence;
- no mutation of source Combo tables;
- no recorded-motion drift during display resolution.

The corpus does not contain facing traces. Therefore mask involution is E6
property evidence, while actual side switches and cross-ups remain `UNKNOWN`.
All timelines are string gap sequences and contain no zero-gap line. This does
not prove the game never emitted same-frame observations; same-frame Runtime
coverage remains unproven.

## 9. Evidence Limits

Not proven by this corpus run:

- recording hooks observe every real-game input or Action exactly once;
- hitstop, same-frame, side-switch, and action-instance timing are correct;
- demo or playback injects the complete sequence at the correct game frames;
- fast-forward/catch-up behavior is correct in REFramework;
- all current Moves, raw AC edges, or raw BCM routes are covered;
- current artifacts can be regenerated byte-identically from authoritative raw
  inputs in this repository;
- any behavior is real-game verified.
