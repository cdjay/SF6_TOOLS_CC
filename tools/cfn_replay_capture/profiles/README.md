`precise-review.json` 保留作为以后逐条定义问题的空白起点，不是当前启用配置。

## 精准问题定义

`precise-review.json` 是逐条定义问题的起始配置，规则列表有意留空。
它关闭“包含系统规则”（`include_system: false`），只列出启用且命中的自定义规则。
空配置的问题列表和问题级别统计均为空，历史人工确认也不会绕过该选择。
全部受伤、防御与资源事实仍保留；“全部防御”仍可查看事实，“机会待核对”受配置控制。
事实提取仍由程序完成，不由配置编写。旧配置未填写此开关时保持原有系统规则行为。

游戏读取 `reframework/data/cfn-replay-rules.json`，网页可以导入本配置，
保存到游戏时使用上述固定文件名。游戏面板显示实际加载的配置名称。
配置文件无效时会显示错误；首次读取退回系统规则，更新时保留上次有效结果。

逐条定义时确认：观察哪方、事实与必要条件、排除条件、证据不足如何处理、
显示名称、级别、跳转依据，以及至少一处符合和一处不符合的录像位置。
不要只凭伤害大小推断投技，不把未采到的值当作零，不把自动判断标为人工确认。
当前条件作用于受伤与防御事件；新问题若需要其他事实或时序，先补充实现与验证。

加载已保存事实后，暂停录像，修改并保存配置，点击“更新规则”。
也可勾选“自动读取规则”。此过程不重新采集、不重播、不改原始伤害总量。
P0 仍保留给人工确认，自定义规则支持 P1、P2、P3。
