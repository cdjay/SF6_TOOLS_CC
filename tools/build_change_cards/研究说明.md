# 0803 → 1013 深度核对说明

## 这次补查了什么

第一轮报告的动作键核对仅覆盖 CharacterAsset 下的节点。本次扩展为所有命名空间的 `*Key`，补查了 app.battle.VfxKey 和 WindKey。因此毒蛇、艾莲娜、本田以及英格丽德、亚思敏的表现层资料比第一轮更完整。第一轮“未发现差异”不能用于这些新补查的表现层项目。

逐角色研究 JSON 保存全部可比嵌套值、新版完整节点、输入引用链及来源路径。普通分支、ShotKey.ActionId 和 LockKey.Type=1 的 Param01 引用分开标注；最后一种只是参数引用证据，没有擅自批准为稳定动作身份或原生函数语义。

所有时间段都是动作内部窗口，不是比赛录像帧。旧版缺继承窗口时，新版出现的时间段只代表“现在读到了”，不代表该窗口刚新增。

## 英格丽德：不是五个笼统的平衡调整

### 1. 状态开关移除

普通投输入715 → 分支717 → 后续动作724/726。两个后续动作各移除一个 `SystemFlag=268435456` 的 SwitchKey。已定位到投的后续流程，但缺少这一个位的枚举定义，不能解释为无敌、取消、防御状态或伤害变化。

### 2. 12个推挤框节点

726 中的 `LockKey(Type=1, Param01=725)` 引用725。725原动作总长179F不变。新增的是同一1号推挤框的12项时间段／偏移记录，而不是12个不同攻击判定框：

所有新增节点 Attribute=4、Condition=0。推挤框与攻击框是不同节点类型；偏移原始单位也不能直接当作游戏距离单位。可确认投的联动引用动作中新增了推挤处理记录，最终站位、角落行为与实际作用对象还需要实机验证。

### 3. 运动定点值

725中一个 SteerKey 的 FixValue 从1680330变成1507328，声明类型为 `via.sfix`。按照项目已有的65536定点比例，数值是25.639801 → 23.000000，差约−2.639801。当前作用窗口81～82，OperationType=1、ValueType=0、TargetType=0。这是一个运动参数，不是动作总帧、发生、收招或伤害。缺少这些枚举的完整语义，不能直接叫作“移速降低10.3%”。

### 4. 飞行道具数据引用

1222/1223/1224由 `214214+LP` 对应输入或MP阶段分支进入；它们的ShotKey依次生成1237/1238/1239，后者再生成1276。HP一侧1227/1228/1229 → 1241/1242/1243 → 1277。

1276与1277的Projectile.DataIndex从共用71改成77、78。已找到直接生成引用链，但这些数据模板本身没有在导出中展开。可以说“两个生成物改用不同数据引用”，不能说弹速、击中硬直、伤害或范围发生了多少变化。

### 5. 40处位置曲线采样

输入1287（236236+P） → 1292（Type37分支） → LockKey引用1293。1293的轴0 PlaceKey窗口0～490、Ratio=65536，PosList共490个采样。

采样414～452与454共40项改变，单项原始差为−1到−23。最大绝对差23／65536≈0.000351。这是联动引用动作的微小位置曲线变化；不应描述为“攻击距离增加”“发生减少”或“收招缩短”。采样序号与实际世界坐标的映射未被本报告额外假定。

### 6. 补查特效

214214+P相关阶段1222～1224与1227～1229各移除一个特效节点；1273有特效结束参数调整。它们是表现层差异，不等于删除攻击判定。

## 仍然无法由离线文件证明的部分

1. 部分状态、继承、锁定、特效操作枚举的实际行为；需要原生枚举或实机验证，不使用猜测补齐。
2. 飞行道具数据引用所指向的完整模板、判定框实体尺寸、完整攻击伤害表，当前导出未覆盖。
3. 0803缺准确取消组字典键与继承帧窗口，不能完整比较全部取消目标和时间窗。
4. 跨版本Move身份尚未批准，所有同编号比较和去编号图一致均为复核候选。
5. 官网中文页部分招式仍使用英文。页面保留其原名与指令，不自行创作中文译名。汉字招式名沿用采集原名。

因此，“深度核对”指现有证据的深入追踪和量化，不表示所有内部枚举都已逆向完成。
